# Design System Tokens & Guidelines (Enterprise)

This folder contains **design tokens** and **variant guidelines** to power the UI layer.

Constraints:
- No pages
- No auth/dashboard
- Create-only (no modifications to existing app entry files)

Naming:
- `tokens/*.ts` export token objects
- `css-variables.ts` exports a CSS variables map
- `variants.ts` exports component variant definitions (Button/Input/Card/Modal/Toast)
- `guidelines/*` contains textual guidance and token usage rules
