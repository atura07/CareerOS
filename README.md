## Overview

CareerOS is a full-stack, AI-powered platform designed to help students and professionals streamline their placement preparation. It combines resume management, ATS analysis, job application tracking, skill development roadmaps, coding practice dashboards, and mock interview tools — all within a single, cohesive interface.

Built with a modern **React + TypeScript + Vite** frontend and a **Spring Boot + Java + MySQL** backend, CareerOS delivers a responsive, secure, and performant experience.

## Features

| Feature | Description |
|---|---|
| **🔐 JWT Authentication** | Secure login and registration with Spring Boot Security and JWT token-based authentication. |
| **📄 Resume Management** | Upload, view, rename, and delete resumes (PDF/DOCX). Text extraction powered by Apache PDFBox and Apache POI. |
| **📊 ATS Resume Analyzer** | Score your resume against ATS parsers. Get keyword matching, section-wise scores, missing keywords, and improvement suggestions. |
| **🏢 Company Dashboard** | Browse top placement companies with detailed profiles, hiring processes, and preparation resources. |
| **📋 Application Tracker** | Track job applications across statuses (Wishlist, Applied, OA Scheduled, Interview, Offer, Rejected). Supports CRUD operations with search, filter, and sort. |
| **🗺️ Roadmap Generator** | Generate personalized placement preparation roadmaps based on target company, role, duration, and current skills. Includes weekly plans, DSA tasks, projects, and resources. |
| **💻 LeetCode Dashboard** | Monitor LeetCode progress with stats, difficulty chart, daily challenge, contest info, and contribution heatmap. |
| **🐙 GitHub Dashboard** | Track GitHub activity with profile stats, contribution graph, language distribution, pinned repos, and activity timeline. |
| **🎤 Mock Interview Dashboard** | Practice with curated interview questions, track performance, and review feedback. |
| **🎯 Placement Readiness Dashboard** | Unified analytics dashboard showing overall readiness score, ATS trends, GitHub/LeetCode activity, application stats, and interview performance. |

## Getting Started

### Prerequisites

| Tool | Version | Installation |
|---|---|---|
| Java JDK | 17+ | [Download](https://adoptium.net/) |
| Node.js | 18+ | [Download](https://nodejs.org/) |
| MySQL | 8.0+ | [Download](https://dev.mysql.com/downloads/) |
| Maven | 3.9+ | [Download](https://maven.apache.org/download.cgi) |

### Backend Setup

```bash
# 1. Create the MySQL database
mysql -u root -p -e "CREATE DATABASE IF NOT EXISTS careeros;"

# 2. Navigate to the backend directory
cd backend

# 3. Configure database credentials in application.properties
#    Edit: src/main/resources/application.properties
#    spring.datasource.username=root
#    spring.datasource.password=your_password

# 4. Build the project
mvn clean install

# 5. Run the application
mvn spring-boot:run
```

The backend starts at `http://localhost:8080`. The API base path is `/api`.

### Frontend Setup

```bash
# 1. Navigate to the frontend directory
cd frontend

# 2. Install dependencies
npm install

# 3. Configure environment variables
#    Create a .env file with:
#    VITE_API_BASE_URL=http://localhost:8080/api

# 4. Start the development server
npm run dev
```

The frontend starts at `http://localhost:5173`.

### Verify Everything Works

```bash
# Run backend tests
cd backend && mvn test

# Build backend
cd backend && mvn clean install

# Type-check frontend (no errors)
cd frontend && npx tsc -p tsconfig.app.json --noEmit

# Build frontend for production
cd frontend && npm run build
```

## Environment Variables

### Frontend (`frontend/.env`)

| Variable | Required | Default | Description |
|---|---|---|---|
| `VITE_API_BASE_URL` | Yes | `http://localhost:8080/api` | Backend API base URL |
| `VITE_SUPABASE_URL` | No | — | Supabase project URL (optional) |
| `VITE_SUPABASE_ANON_KEY` | No | — | Supabase anonymous key (optional) |

> **Note:** Supabase is optional. Active authentication is handled by Spring Boot JWT. The app starts and runs normally without Supabase environment variables.

### Backend (`backend/src/main/resources/application.properties`)

| Property | Required | Default | Description |
|---|---|---|---|
| `server.port` | No | `8080` | Server port |
| `spring.datasource.url` | Yes | `jdbc:mysql://localhost:3306/careeros...` | MySQL connection URL |
| `spring.datasource.username` | Yes | `root` | MySQL username |
| `spring.datasource.password` | Yes | — | MySQL password |
| `spring.jpa.hibernate.ddl-auto` | No | `update` | Hibernate DDL mode |
| `application.security.jwt.secret-key` | Yes | — | JWT signing secret |
| `application.security.jwt.expiration` | No | `86400000` | JWT expiration (ms) |
| `spring.servlet.multipart.max-file-size` | No | `5MB` | Max upload file size |
| `application.resume.upload-dir` | No | `uploads` | Resume upload directory |

## API Overview

All endpoints are prefixed with `/api/v1`. Authentication is via JWT Bearer token in the `Authorization` header.

### Authentication

| Method | Endpoint | Description | Auth |
|---|---|---|---|
| `POST` | `/api/v1/auth/register` | Register a new user | No |
| `POST` | `/api/v1/auth/authenticate` | Login and receive JWT token | No |

### Resumes

| Method | Endpoint | Description | Auth |
|---|---|---|---|
| `POST` | `/api/v1/resume/upload` | Upload a resume file (PDF/DOCX) | Yes |
| `GET` | `/api/v1/resume` | List all user resumes | Yes |
| `GET` | `/api/v1/resume/{id}` | Get a resume by ID | Yes |
| `DELETE` | `/api/v1/resume/{id}` | Delete a resume | Yes |

### ATS Analysis

| Method | Endpoint | Description | Auth |
|---|---|---|---|
| `GET` | `/api/v1/ats/analyze/{resumeId}` | Analyze a resume by ID | Yes |
| `POST` | `/api/v1/ats/analyze/text` | Analyze raw text directly | Yes |
| `POST` | `/api/ats/analyze` | Analyze resume against job description | Yes |

### Applications

| Method | Endpoint | Description | Auth |
|---|---|---|---|
| `GET` | `/api/v1/applications` | List all user applications | Yes |
| `GET` | `/api/v1/applications/{id}` | Get an application by ID | Yes |
| `POST` | `/api/v1/applications` | Create a new application | Yes |
| `PUT` | `/api/v1/applications/{id}` | Update an application | Yes |
| `DELETE` | `/api/v1/applications/{id}` | Delete an application | Yes |

### Roadmaps

| Method | Endpoint | Description | Auth |
|---|---|---|---|
| `GET` | `/api/v1/roadmaps` | List all user roadmaps | Yes |
| `GET` | `/api/v1/roadmaps/{id}` | Get a roadmap by ID | Yes |
| `POST` | `/api/v1/roadmaps` | Create a new roadmap | Yes |
| `PUT` | `/api/v1/roadmaps/{id}` | Update a roadmap | Yes |
| `DELETE` | `/api/v1/roadmaps/{id}` | Delete a roadmap | Yes |

## Deployment

### Backend (Production)

```bash
# Build the JAR
cd backend
mvn clean package -DskipTests

# Run the JAR
java -jar target/careeros-backend-0.0.1-SNAPSHOT.jar
```

For production deployment, consider:

- **Database:** Use a managed MySQL service (AWS RDS, DigitalOcean Managed DB, PlanetScale).
- **JWT Secret:** Set a strong, unique secret key via environment variable or external config.
- **Reverse Proxy:** Place Nginx or Caddy in front of the Spring Boot app.
- **SSL:** Enable HTTPS with Let's Encrypt.
- **Docker:** Containerize the backend for consistent deployments.

### Frontend (Production)

```bash
# Build for production
cd frontend
npm run build

# Output is in frontend/dist/
# Serve with any static file server (Nginx, Vercel, Netlify, Cloudflare Pages)
```

For production deployment, consider:

- **Static Hosting:** Deploy to Vercel, Netlify, or Cloudflare Pages.
- **Environment Variables:** Set `VITE_API_BASE_URL` to the production backend URL.
- **CDN:** Enable CDN caching for static assets.
- **Compression:** Enable gzip/brotli compression.

### Docker Deployment (Recommended)

```dockerfile
# Backend Dockerfile
FROM eclipse-temurin:17-jre-alpine
COPY target/careeros-backend-*.jar app.jar
EXPOSE 8080
ENTRYPOINT ["java", "-jar", "/app.jar"]
```

```dockerfile
# Frontend Dockerfile (multi-stage)
FROM node:20-alpine AS build
WORKDIR /app
COPY package*.json ./
RUN npm ci
COPY . .
RUN npm run build

FROM nginx:stable-alpine
COPY --from=build /app/dist /usr/share/nginx/html
COPY nginx.conf /etc/nginx/conf.d/default.conf
EXPOSE 80
CMD ["nginx", "-g", "daemon off;"]
```
